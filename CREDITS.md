# Credits

The RK3566 + ESP32S3 system was developed with reference to the public project [shengqing1/openmv-stm32](https://github.com/shengqing1/openmv-stm32). This repository retains the interoperable 7-byte serial frame format and hardware-level project context. The ESP32S3 parser, PID controller, and firmware implementation in this release are independently written. No source files from that repository are included.
